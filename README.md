# UbuntuHub

## Community Support Android Application

UbuntuHub is an Android community-support application designed to connect
people within local communities who need assistance with people who are
willing and able to help.

The application focuses on creating a safe and accessible platform where
users can request assistance, offer assistance, share items, and access
useful community information.

---

## Purpose

The purpose of UbuntuHub is to encourage community participation and
support by providing users with a platform where they can:

- Request help from members of their community.
- Offer assistance to other community members.
- Share useful items.
- Discover relevant community posts.
- Communicate with other users.
- Manage their profile and application settings.

---

## Technologies

The UbuntuHub prototype is being developed using:

- Kotlin
- Android Studio
- Jetpack Compose
- Firebase Authentication
- ASP.NET Core Web API
- PostgreSQL
- Retrofit
- GitHub
- GitHub Actions

Additional technologies will be incorporated as development progresses.

---

## Main Features

The prototype will include:

- User registration
- User login
- Secure authentication
- User settings
- Community feed
- Community posts
- Help requests
- Help offers
- Search and filtering
- REST API integration
- Online database

- Input validation
